# Bip Boop development handoff

Project: custom Amazfit Bip Max watch face

- Primary target: Amazfit Bip Max
- Physical resolution: 432 x 514
- Zepp OS: 5.0
- Latest device API level at setup: 4.4
- Device source: 11206915
- Screen type: square (`s`), with the dedicated `w432` target

The current UI implements the owner-supplied regular and AOD designs. Treat the 432 x 514 reference layouts, pure-black backgrounds, Archivo typography, and live-data composition as product requirements unless the owner supplies a revised design.

Before changing target configuration or screen adaptation logic, read the official [Bip Max screen adaptation documentation](https://docs.zepp.com/docs/guides/framework/device/screen-adaption/). In particular, preserve `_pikeCompatibled`, `st: s`, `sr: w432`, `dw: 432`, the 432 design width, and device source 11206915 unless current official guidance explicitly replaces them.

This project intentionally targets only the Bip Max. The Bip 6 configuration generated by `npm run dev:bip6` is a disposable simulator fallback and must not replace the production target.
